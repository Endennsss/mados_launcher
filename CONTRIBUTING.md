# Как работать с Mados Launcher

## Перед изменениями

1. Опишите пользовательский сценарий и источник данных.
2. Проверьте, затрагиваются ли IPC, миграция, аккаунты, deep links или существующие данные.
3. Для интерфейса сверяйтесь с [правилами стиля](docs/INTERFACE_STYLE_GUIDE.md).
4. Для worker-изменений заранее определите успешный результат, ошибку, отмену и восстановление после перезапуска.

## Правила pull request

- Один PR решает одну связанную задачу.
- Заголовок пишется в повелительном стиле и начинается с области: `feat(ui):`, `fix(worker):`, `test:`, `docs:`, `ci:` или `build:`.
- В описании укажите проблему, итоговое поведение, затронутые слои и способ проверки.
- Изменение интерфейса сопровождается скриншотом до/после или коротким видео, если это возможно.
- Изменение IPC обновляет `launcher.ts`, `schema.ts`, `ipc.schema.json` и contract-тесты в одном PR.
- Изменение хранения данных описывает схему, миграцию, резервную копию и откат.
- Нельзя передавать токены в renderer, добавлять mock-сервера, скрывать ошибки или удалять существующие сценарии.
- Не смешивайте массовое форматирование и функциональный код.
- Не добавляйте секреты, локальные базы, `node_modules`, Debug-артефакты и пользовательские данные.

## Обязательные проверки

Для C#:

```powershell
dotnet build SS14.Launcher.sln --configuration Debug
dotnet test SS14.Launcher.sln --configuration Debug --no-restore
```

Для Electron:

```powershell
cd Mados.Launcher
npm ci
npm run typecheck
npm test -- --run
npm run build
```

Для изменения упаковки дополнительно запускайте `npm run prepare-worker` и Debug smoke упакованного приложения. В описании PR перечислите непроверенные платформы.

## Проверка PR ревьюером

- Поведение соответствует задаче и не заменяет реальную функцию заглушкой.
- Loading, empty, error, disabled и reduced-motion состояния оформлены.
- IPC allowlist и валидация параметров не расширены без причины.
- Секреты остаются в worker, а логи очищены от чувствительных данных.
- Тесты проверяют пользовательский результат, а не только строки реализации.
- Документация, screenshots и release notes обновлены, если это влияет на пользователя.
