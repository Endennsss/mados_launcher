# Mados Launcher Bootstrap Installer — дизайн

## Цель

Добавить отдельный небольшой установщик Mados Launcher. Установщик не содержит запакованные файлы самого лаунчера: он получает последнюю стабильную Windows x64 ZIP-сборку из GitHub Releases, распаковывает её в выбранный пользователем каталог и запускает приложение.

Работа остаётся локальной. Commit и push в рамках этой задачи не выполняются.

## Пользовательский поток

1. Пользователь запускает `Mados Installer.exe`.
2. Установщик показывает округлённое окно в текущем тёмно-красном стиле Mados Launcher и автоматически проверяет последний стабильный релиз репозитория `Endennsss/mados_launcher`.
3. На экране отображаются версия, размер ZIP и целевая платформа. Пререлизы пропускаются.
4. Пользователь выбирает каталог установки или принимает предложенный путь.
5. Установщик скачивает asset `Mados.Launcher.Windows.x64.zip` по HTTPS во временный каталог, показывает реальный прогресс и поддерживает отмену.
6. ZIP проверяется до распаковки. Каждый путь внутри архива нормализуется и обязан оставаться внутри временного каталога распаковки.
7. Содержимое распаковывается во временный каталог рядом с выбранным местом. После успешной распаковки каталог переносится в место установки атомарно настолько, насколько позволяет Windows.
8. При существующей установке процесс Mados Launcher завершается штатно через IPC/закрытие окна; пользовательские каталоги `data`, `launcher` и локальные базы не удаляются. `resources/app.asar` относится к runtime лаунчера и заменяется новой версией. Перед заменой создаётся резервная копия только заменяемых файлов.
9. После успеха запускается `Mados Launcher.exe`, а установщик закрывается. При ошибке временные файлы удаляются, существующая установка остаётся нетронутой, появляется кнопка повтора.

## Архитектура

Создаётся самостоятельный Electron + React + TypeScript проект `Mados.Installer`. В его пакет не включаются `Mados.Launcher/dist`, C# worker или содержимое релизного ZIP. В пакет попадают только Electron runtime, main/preload/renderer установщика и брендовые ассеты.

Main process отвечает за GitHub API, download stream, отмену, временные каталоги, ZIP-проверку, распаковку, замену каталога и запуск установленного приложения. Renderer получает только типизированные события прогресса и вызывает allowlist-команды через preload. Renderer не имеет доступа к `fs`, `process`, `child_process` или произвольным URL.

## GitHub Releases

- API: `https://api.github.com/repos/Endennsss/mados_launcher/releases/latest`.
- Релиз принимается только при `draft === false` и `prerelease === false`.
- Asset выбирается по точному имени `Mados.Launcher.Windows.x64.zip`; если имя не найдено, показывается структурированная ошибка.
- Скачивание разрешено только по HTTPS и только на URL, полученному из GitHub API.
- User-Agent задаётся как `Mados-Installer/<version>`.
- При отсутствии сети, rate limit или повреждённом JSON показывается понятная ошибка с повтором.

## IPC-контракт

Внутренний контракт установщика хранится в `Mados.Installer/src/contracts/installer.ts` и проверяется схемой.

Команды:

- `release.check` — получить последний стабильный релиз;
- `install.chooseDirectory` — открыть системный выбор каталога;
- `install.start` — скачать и установить выбранный asset;
- `install.cancel` — отменить текущую операцию;
- `install.openDirectory` — открыть выбранный каталог после установки;
- `app.quit` — закрыть установщик.

События:

- `installer.stage` — `checking`, `ready`, `downloading`, `extracting`, `installing`, `launching`, `completed`, `error`;
- `installer.progress` — полученные байты, общий размер и процент;
- `installer.error` — код, безопасное сообщение и возможность повтора.

Ответы не содержат токенов, credentials или полных локальных путей, кроме выбранного пользователем пути, необходимого для отображения.

## Интерфейс

Окно frameless с теми же CSS design tokens, логотипом кота и скруглением 20 px. Основной экран состоит из брендинга, карточки релиза, поля каталога, кнопки действия и ленты стадий. Кнопка загрузки использует Lucide `Download`, выбор папки — `FolderOpen`, отмена — `X`, повтор — `RefreshCw`.

Анимации короткие и семантические: `Download` повторяется только при реальной загрузке, `PackageOpen` проигрывается после распаковки, `FolderOpen` слегка раскрывается при наведении, `RefreshCw` делает один оборот при повторе. При `prefers-reduced-motion` transform-анимации отключаются.

## Безопасность и сохранность данных

- ZIP path traversal блокируется до записи файлов.
- Симлинки и неожиданные абсолютные пути в ZIP отклоняются.
- Запись идёт во временную папку, а не напрямую поверх установки.
- Существующая установка не удаляется, если скачивание, проверка или распаковка не завершились успешно.
- Временные каталоги удаляются в `finally`.
- Запуск после установки выполняется только для ожидаемого `Mados Launcher.exe` внутри выбранной папки.
- В логах не печатаются секреты и содержимое пользовательских баз.

## Тестирование и сборка

Unit-тесты проверяют: выбор стабильного релиза, точный asset, отказ HTTP и внешнего URL, расчёт прогресса, отмену, защиту path traversal, абсолютные пути и симлинки, сохранность старой установки при ошибке и запуск ожидаемого executable.

UI smoke проверяет: отображение последнего релиза, выбор каталога, загрузку и прогресс, распаковку, ошибку сети, отмену, повтор и запуск установленного лаунчера.

Сборка установщика выполняется отдельным electron-builder конфигом и создаёт `Mados.Installer.Windows.x64.exe`. Обычная сборка Mados Launcher остаётся без изменений.
