# Mados Launcher 0.42.1

Исправлены русские названия серверов, получение карты и режима и загрузка описания сервера.

## Исправления

- Русские названия, эмодзи и другие Unicode-символы больше не искажаются при подключении и сохранении: обмен между Electron и C# worker явно использует UTF-8 на Windows.
- Имя недавнего сервера обновляется по его свежему статусу. Это восстанавливает ранее повреждённое название, сохраняя дату подключения, статистику и историю других аккаунтов. Если сервер недоступен, восстановление произойдёт после успешного обновления.
- Карта и режим читаются из публичных полей `map` и `preset` в `/status` и каталоге hub. Теги `map:` и `mode:` остаются резервным источником. Эти данные используются в карточках и Discord Presence; уровень RP не подменяет режим игры.
- Нестандартный формат дополнительных полей больше не мешает получить остальные данные сервера. Если сервер не публикует карту или режим, они остаются неизвестными.
- Описание запрашивается напрямую у сервера, с резервным запросом через hub. Учтены адреса с завершающим `/` и без него. Ошибка загрузки описания больше не скрывает доступный статус, онлайн, ping, карту и режим.

## Что скачать

- **Mados.Installer.Windows.x64.exe** — установщик, который скачивает ZIP последнего стабильного релиза в выбранную папку.
- **Mados.Launcher.Windows.x64.zip** — полная **Release-сборка** для Windows x64. Распакуйте весь архив и запускайте `Mados Launcher.exe` вместе с соседними файлами.
- **Mados.Launcher.Windows.x64.exe** — NSIS-пакет, который также используется встроенным обновлением.
- Для Windows ARM64, macOS и Linux доступны пакеты соответствующих архитектур.

ZIP содержит **Release worker и Loader**, не Debug. Установщик не содержит встроенную копию лаунчера. Контрольные суммы опубликованы в `SHA256SUMS.txt`; `latest*.yml`, `.blockmap` и `.sha512` используются обновлением.

## Проверки

Проверены C#-тесты, TypeScript-тесты и типы, тесты установщика и сборки релизных файлов. Добавлена Windows CI-проверка настоящего worker: UTF-8 через IPC, подключение к тестовому локальному HTTP-серверу, сохранение и перезапуск SQLite, получение карты/режима, ошибки описания и восстановление имени без изменения истории других аккаунтов. Данные публичного «Персея» также проверены через worker.

Аккаунты, игровые файлы и локальные данные сохраняются. Обновление скачивается по кнопке и не прерывает игру. Пакеты без цифровой подписи (unsigned); Linux ZIP обновляется вручную. Полный вход в игровой раунд и отображение в установленном Discord при подготовке этого исправления не проверялись.
