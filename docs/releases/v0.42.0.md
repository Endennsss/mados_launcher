# Mados Launcher 0.42.0

Личные инструменты, обновлённые разделы лаунчера и исправления интерфейса.

## Новые возможности

- **Мой Mados** — экспорт избранного, профилей запуска, заметок и оформления. Перед восстановлением доступен предпросмотр и выбор разделов; сохраняется копия прежнего состояния. Пароли и токены в архив не входят.
- **Перенос игрового кэша** на другой диск: выбор папки, проверка скопированных файлов, реальный прогресс, отмена и переключение после перезапуска.
- **Библиотека реплеев и бандлов**: добавление ZIP через диалог или перетаскиванием, поиск, названия, заметки и отметка просмотра. Удаление записи сохраняет исходный файл.
- **Ожидание свободного места** на выбранном сервере с уведомлением внутри лаунчера. Проверка выполняется раз в 30 секунд, до 30 минут; место не резервируется и автоматическое подключение не выполняется.
- **Диагностика подключения** и управление местом на диске с предварительным просмотром очистки и защитой используемых файлов.
- Настройки сворачивания лаунчера после запуска игры и возвращения в Mados после её завершения.

## Интерфейс

- Настраиваемая главная и карточка после игры; панель аккаунтов и темы с предпросмотром.
- Обновлены центр уведомлений, время игры, новости, экран обновления, избранное и профили запуска.
- Поиск по лаунчеру через **Ctrl+K**, поиск по настройкам и краткий гайд для первого запуска.
- Панель текущей игры и инструменты локального сервера с понятными этапами и управлением логами.
- Единые поверхности Mados, красные акценты, связанные анимации Lucide и поддержка уменьшения движения.
- Исправлены двойная обводка полей ввода и расположение кнопки «Добавить ZIP». В узком окне действие переносится на отдельную строку.
- Восстановленное избранное корректно распознаётся в каталоге при разных вариантах записи стандартного порта; повторное добавление одного сервера не создаёт дубликат.

Обновление Mados по-прежнему только предлагается: скачивание начинается по кнопке, перезапуск не прерывает игру. Сохраняются аккаунты, избранное, игровые файлы, Discord Presence, deep links и локальная статистика.

## Что скачать

- **Mados.Installer.Windows.x64.exe** — отдельный установщик в стиле Mados, который скачивает ZIP последнего стабильного релиза в выбранную папку.
- **Mados.Launcher.Windows.x64.zip** — полная **Release**-сборка. Распакуйте весь архив и запускайте `Mados Launcher.exe` вместе с соседними файлами.
- **Mados.Launcher.Windows.x64.exe** — самостоятельный NSIS-пакет, который также используется встроенным обновлением.
- Для Windows ARM64, macOS и Linux доступны файлы соответствующих архитектур.

Пакеты приложения содержат **Release worker и Loader**, не Debug. Файлы `.sha512`, `.blockmap` и `latest*.yml` нужны механизму обновления; `SHA256SUMS.txt` содержит контрольные суммы.

Локальные проверки перед публикацией: 176 TypeScript-теста лаунчера, 101 C#-тест, 49 тестов установщика и 3 проверки сборки релизных файлов. Проверены реальные Release worker/Loader, запуск и штатное завершение Windows-пакета, распаковка и установка нового ZIP, а также интерфейс с темами и уменьшением движения. Пакеты всех шести платформ/архитектур собираются GitHub Actions; публикация выполняется после проверки файлов и контрольных сумм.

Сборки без цифровой подписи (unsigned). Для Linux ZIP обновление выполняется вручную; встроенное обновление Linux рассчитано на AppImage. История и личные данные хранятся локально. Полный вход на публичный игровой сервер и воспроизведение пользовательского реплея при подготовке этой версии не проверялись; эти сценарии не следует считать подтверждёнными одним успешным запуском окна.
