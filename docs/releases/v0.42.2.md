# Mados Launcher 0.42.2

Серая тема оформления и наглядный прогресс загрузки игровых файлов.

## Изменения

- В настройках оформления появилась тема «Серая» с нейтральной графитовой палитрой. Выбор сохраняется между запусками и поддерживается резервными копиями настроек.
- Полоса загрузки стала заметнее. Во время скачивания отображаются процент и скачанный объём в байтах, КБ или МБ; для контента из манифеста показывается количество полученных файлов из общего числа.
- Исправлена передача прогресса из C# worker в интерфейс: вместо пустого объекта передаются скачанное количество, общий размер и единица измерения.
- Если общий размер неизвестен, отображается полученный объём и индикатор ожидания без выдуманного процента.

## Что скачать

- **Mados.Installer.Windows.x64.exe** — установщик последнего стабильного релиза.
- **Mados.Launcher.Windows.x64.zip** — полный лаунчер для Windows x64; распакуйте архив целиком.
- **Mados.Launcher.Windows.x64.exe** — NSIS-пакет для установки и встроенного обновления.
- Для Windows ARM64, macOS и Linux доступны пакеты соответствующих архитектур.

Контрольные суммы опубликованы в `SHA256SUMS.txt`. Аккаунты, игровые файлы и настройки сохраняются.

## Проверки

Локально проверены 179 TypeScript-тестов лаунчера, 105 C#-тестов, типы, сборка интерфейса и C# worker. Проверены 3 теста сборки релизных файлов. Установщик проходит отдельную проверку на Windows в релизном workflow; локально на Linux 3 его теста с Windows-путями не проходят. Дополнительно проверены реальные события worker для прогресса в байтах, файлах и сброса прогресса. Полное скачивание контента с игрового сервера при подготовке релиза не проверялось.
