# Mados Launcher 0.41.0

Обновлённый интерфейс и исправления загрузки серверов, установщика и обновлений.

- Единое оформление разделов, меню, подтверждений и подсказок в стиле Mados; связанные анимации и поддержка уменьшения движения.
- Переработаны карточка последнего сервера, боковое описание и панель запуска с реальными стадиями C# worker.
- Каталог показывает серверы по мере получения данных. Индивидуальный ping загружается в фоне, повторное открытие использует кеш; ручное обновление обновляет данные заново.
- Каталог и инструменты стали компактнее: дополнительные действия раскрываются по необходимости, управление локальным сервером соответствует его состоянию.
- Убрано требование обновлять официальный SS14 Launcher. Mados проверяет собственные стабильные релизы GitHub при запуске и раз в час.
- Новая версия только предлагается: скачивание по кнопке, установка через «Перезапустить и обновить» после завершения игры. Обычное закрытие не устанавливает обновление.
- Сохранены исправления распаковки установщика, ярлыков и иконок Windows. Установщик скачивает ZIP последнего стабильного релиза в выбранную папку.

## Что скачать

- **Mados.Installer.Windows.x64.exe** — установщик в стиле Mados; скачивает ZIP с GitHub.
- **Mados.Launcher.Windows.x64.zip** — полная **Release**-сборка для ручной распаковки. Запускайте `Mados Launcher.exe` вместе с остальными файлами из архива.
- **Mados.Launcher.Windows.x64.exe** — самостоятельный NSIS-пакет, также используется встроенным обновлением.
- Для Windows ARM64, macOS и Linux доступны соответствующие архитектурные файлы.

Все пакеты содержат Release worker и Loader. Данные аккаунтов, избранное и игровые файлы сохраняются. Файлы `.sha512`, `.blockmap` и `latest*.yml` нужны механизму обновления; `SHA256SUMS.txt` содержит контрольные суммы загрузок.

Сборки без цифровой подписи (unsigned). Windows x64 проверен локально; остальные платформы собираются в CI. Для Linux ZIP обновление выполняется вручную; встроенное обновление Linux рассчитано на AppImage.
